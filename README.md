# RPA 프로젝트

## 개요
이 리포지토리는 RPA(로봇 프로세스 자동화) 프로젝트를 포함하고 있으며, UiPath를 이용하여 다양한 업무 자동화를 구현한 내용을 담고 있습니다.

## 주요 기능
- **데이터 추출 및 가공**: 다양한 데이터 소스에서 데이터를 추출하고 가공하는 기능 구현
- **업무 자동화**: 반복적인 업무를 자동화하여 효율성을 높임
- **프로젝트 실습**: 실제 업무 환경을 고려한 프로젝트 실습 및 구현

## 학습 내용
- **UiPath 기본 구조 및 설치**
- **VB.NET을 사용한 코드 작성**: 기본적인 VB.NET 이해 및 활용
- **Excel 자동화**: 데이터를 처리하고 결과를 저장하는 작업
- **Email Automation**: 자동으로 이메일을 전송하고 관리하는 기능

## 사용 기술
- **RPA Tools**: UiPath Studio
- **Programming Languages**: VB.NET (기본적인 이해 및 활용)
- **Framework**: .NET Framework
- **Other Tools**: Excel, PDF
- **OS**: Windows 10
